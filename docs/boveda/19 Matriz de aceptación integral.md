# Matriz de aceptación integral
Ninguna lista demuestra que «nada falta» para siempre: mantener esta matriz con cambios de alcance.
| Área | Criterio verificable | Estado |
|---|---|---|
| Marca | NOBRALTA elegida; disponibilidad legal/dominios/redes por verificar | Elección confirmada; verificaciones pendientes |
| Producto | Composición por componente, medidas y fotos autorizadas | Pendiente |
| UX | Compra móvil y fuera de horario probadas con usuarios | Pendiente |
| Visual | Tokens aplicados y todos los componentes estilizados | Pendiente |
| Accesibilidad | Contraste, teclado, zoom, lector y errores revisados | Pendiente |
| Compra | Precio/stock/envío consistentes y última unidad concurrente | Pendiente |
| Pagos | Medio versionado, operación texto, UTC y revisión real | Pendiente |
| Archivos | Conversión legible, permisos, límites y reintento | Pendiente |
| Envío | Tarifas vigentes, datos mínimos y seguimiento protegido | Pendiente |
| Afiliados | Atribución, devengo, ajuste y pago sin duplicados | Pendiente |
| Personal | Reglas laborales validadas, asistencia y observaciones | Pendiente |
| Seguridad | Autorización por recurso, 2FA, secretos y auditoría | Pendiente |
| SEO | Rastreabilidad, variantes, schema, sitemap y canónicos | Pendiente |
| Marketing | Métricas sin PII, consentimiento y presupuesto | Pendiente |
| Legal/consumidor | Identidad comercial, privacidad, términos, cambios, reclamaciones y comprobantes revisados para Perú | Pendiente |

| Rendimiento | Medidas reales móvil y desconexión; no solo puntuación de laboratorio | Pendiente |

Revisar con propietario: aprobar o modificar cada área, responsable y evidencia. No afirmar conformidad legal, WCAG o seguridad solo por completar documentos.
