Notificaciones:
Distinguir avisos con web abierta de push con aplicación cerrada.
WhatsApp/correo/push requieren integración real, permisos y costos.
No prometer automatización no verificada.

Mantenimiento:
No existe cero mantenimiento.
Staging, pruebas, dependencias fijadas, actualizaciones planificadas y parches.
Respaldo y prueba de restauración.
Rollback de código no revierte automáticamente cambios destructivos de base de datos.
